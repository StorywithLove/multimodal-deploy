## 关键概念：12Hz 不等于 12kHz

模型名 `12Hz` 指音频 token 帧率（官方配置 `_frame_rate=12.5`），不是波形每秒采样数。官方 tokenizer 配置的输入 / 输出波形采样率为 24000 Hz。

题目文字要求“采样率（12kHz）”，对话方案选择生成后真实重采样至 12000 Hz 再保存。不能直接把 24kHz 波形用 `sf.write(..., 12000)` 写出，否则改变播放速度与音调。

后续若平台明确要求原生 24kHz，应按其实际检测规则调整；本轮没有采样率验收输出，不宣称已独立确认平台要求。

参考音频文本应与音频一致。题目 curl 示例“大哥的问题，自然也就是我的问题。”不能未经试听就当成指定 MP3 的转写。若未知参考原文，官方允许 `x_vector_only_mode=True`，仅提取音色，但克隆质量可能降低；有准确原文时使用完整克隆模式。

## 共用推理模块

先在 Notebook 单独单元格创建目录：

```python

```

将以下内容保存到云端 `/data/exam/tts_common.py`。Notebook 中可在代码前加首行 `%%writefile /data/exam/tts_common.py`，魔法命令必须是单元格第一行，不写入 .py 文件。

```python
from pathlib import Path
import librosa
import numpy as np
import soundfile as sf
import torch
from qwen_tts import Qwen3TTSModel

MODEL_NAME = "Qwen3-TTS-12Hz-1.7B-Base"
MODEL_PATH = f"/mnt/moark-models/{MODEL_NAME}"
OUTPUT_PATH = Path("/data/exam/tts_output.wav")
OUTPUT_SR = 12000

def load_model():
    if not Path(MODEL_PATH).is_dir():
        raise FileNotFoundError(MODEL_PATH)
    return Qwen3TTSModel.from_pretrained(
        MODEL_PATH,
        device_map="cuda:0",
        dtype=torch.bfloat16,
        attn_implementation="sdpa",
    )

def synthesize(model, text, ref_audio, ref_text=""):
    ref_text = ref_text.strip()
    with torch.inference_mode():
        wavs, source_sr = model.generate_voice_clone(
            text=text,
            language="Chinese",
            ref_audio=str(ref_audio),
            ref_text=ref_text or None,
            x_vector_only_mode=not bool(ref_text),
        )
    waveform = np.asarray(wavs[0], dtype=np.float32)
    if source_sr != OUTPUT_SR:
        waveform = librosa.resample(
            waveform, orig_sr=source_sr, target_sr=OUTPUT_SR,
        )
    return waveform, OUTPUT_SR

def save_output(waveform, sample_rate):
    OUTPUT_PATH.parent.mkdir(parents=True, exist_ok=True)
    sf.write(
        OUTPUT_PATH, waveform, sample_rate,
        format="WAV", subtype="PCM_16",
    )
```

选择 SDPA 避免先依赖额外 FlashAttention 安装；不要把之前图像模型的“禁用 KV Cache”钩子直接复制到 TTS 的自回归生成中，本轮没有证据要求该修改。

## 任务二：FastAPI 语音合成

保存以下内容到云端 `/data/exam/tts_api.py`，与共用模块放在同一目录：

```python
import base64
import io
import shutil
import tempfile
import threading
from contextlib import asynccontextmanager
from pathlib import Path

import soundfile as sf
import torch
from fastapi import FastAPI, File, Form, HTTPException, UploadFile
from pydantic import BaseModel
from tts_common import MODEL_NAME, load_model, synthesize, save_output

lock = threading.Lock()

@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.tts = load_model()
    try:
        yield
    finally:
        del app.state.tts
        torch.cuda.empty_cache()

app = FastAPI(lifespan=lifespan)

class AudioData(BaseModel):
    b64_json: str

class SpeechResponse(BaseModel):
    data: list[AudioData]

@app.get("/health")
def health():
    return {"status": "ok", "model": MODEL_NAME}

@app.post("/v1/audio/speech", response_model=SpeechResponse)
def speech(
    ref_audio: UploadFile = File(...),
    input: str = Form(...),
    ref_text: str = Form(""),
    model: str = Form(MODEL_NAME),
):
    try:
        if model != MODEL_NAME:
            raise HTTPException(400, f"仅支持 {MODEL_NAME}")
        if not input.strip():
            raise HTTPException(400, "input 不能为空")
        suffix = Path(ref_audio.filename or "").suffix.lower()
        if suffix not in {".wav", ".mp3", ".flac", ".ogg", ".m4a"}:
            raise HTTPException(400, "不支持的参考音频扩展名")
        with lock:
            with tempfile.TemporaryDirectory(prefix="qwen_tts_") as directory:
                reference = Path(directory) / f"reference{suffix}"
                with reference.open("wb") as output:
                    shutil.copyfileobj(ref_audio.file, output)
                if not reference.stat().st_size:
                    raise HTTPException(400, "参考音频为空")
                waveform, sr = synthesize(
                    app.state.tts, input, reference, ref_text,
                )
                save_output(waveform, sr)
                buffer = io.BytesIO()
                sf.write(
                    buffer, waveform, sr,
                    format="WAV", subtype="PCM_16",
                )
                encoded = base64.b64encode(buffer.getvalue()).decode("ascii")
        return SpeechResponse(data=[AudioData(b64_json=encoded)])
    finally:
        ref_audio.file.close()
```

启动时加载一次模型；锁保护模型并串行写入固定输出文件。`tts_output.wav` 每次请求都会覆盖为最新结果，验收前应使用题目目标文本调用。上传临时文件自动清理，base64 包含 WAV 头及音频数据，不仅是裸采样数组。

## 实际踩坑与解决顺序

| 现象 | 判断 | 处理 |
|---|---|---|
| `%%writefile /data/exam/tts_common.py` 抛 FileNotFoundError | 父目录不存在，尚未执行模型代码 | 先在单独单元格 mkdir，再重跑 writefile |
| 导入 tts_common 时 `No module named 'librosa'` | 脚本找到，但当前内核缺依赖 | `%pip install librosa soundfile -i 清华源`，重启后验证 |
| `No module named 'qwen_tts'` | IndexTTS / ASR 的包不能替代 Qwen-TTS | 安装匹配的 qwen-tts，核对计划不覆盖厂商库 |
| 用 `Would install` 判断安装成功 | dry-run 仅解析计划 | 去掉 dry-run 正式安装，再由 import 和 metadata 验证 |
| 认为模型名 12Hz 要直接写 12000 WAV 头 | token 帧率与波形采样率混淆 | 读取返回 sr，再真实重采样 |
| Notebook 模型和 API 同时加载 | 可能重复占显存 | 启动 API 前重启内核，单 worker |

安装与重启后若模块导入仍异常，打印 `sys.executable`、包版本与完整报错；不要不断重装厂商 torch。题目参考 MP3 的解码依赖需以实际环境测试，不把安装 ffmpeg-python 视为已经安装系统 ffmpeg 可执行文件。
