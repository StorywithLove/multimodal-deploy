### 坑一：把 Whisper 代码直接换路径

Whisper 使用以下路线成功：

```python
from transformers import AutoModelForSpeechSeq2Seq, AutoProcessor
# processor(audio, sampling_rate=16000, return_tensors="pt")
# model.generate(input_features)
```

仅将模型路径换成 Qwen3-ASR 后失败：

```text
KeyError: 'qwen3_asr'
Transformers does not recognize this architecture
```

失败发生在架构识别，尚未处理音频，不是显存不足。tokenizer regex 和 torchvision Beta 警告不是该次异常终止位置。

解决：安装并导入官方 `qwen_asr`，使用 `Qwen3ASRModel.from_pretrained()` + `transcribe()`。它仍是 Transformers 后端，不需要启用 `[vllm]` 扩展。不能安装新包后继续原封不动运行 Whisper 的 AutoModelForSpeechSeq2Seq 流程。

### 坑二：安装包多、Gradio 反复回溯

qwen-asr 包包含 Transformers、Accelerate、多语言处理（nagisa / soynlp）、音频工具、Gradio / Flask 演示服务等依赖。nagisa 还会拉取 DyNet38。包多本身符合官方声明，但不代表全部包都是中文单次识别的直接计算依赖。

明确冲突：

```text
gradio 6.28.0: huggingface-hub >=1.16.0,<2.0
transformers 4.57.6: huggingface-hub >=0.34.0,<1.0
```

二者无交集，pip 因而不断下载不同 Gradio 版本。固定 6.28.0 是为尽快暴露冲突，不是有效的最终组合。后来核对 Gradio 6.7.0 允许 Hub `>=0.33.5,<2.0`，与 Hub 0.36.0 有交集。

Terminal 中先预览，再在没有替换厂商核心库时安装：

```bash
python -m pip install --dry-run \
  "qwen-asr==0.0.6" "gradio==6.7.0" "huggingface-hub==0.36.0" \
  -i https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple
```

确认计划后，去掉 `--dry-run` 执行同一命令。ASR 日志的最终 Would install 列表未包含 torch / torchaudio 的替换，但仍有 Transformers、Accelerate、Pydantic、FastAPI 等上层变化，不代表对已有项目完全无影响。此 Gradio 版本仅用于当前识别实验依赖，不据此发布公网演示。

`Would install` 是预览成功，不是安装成功。Notebook 使用 `%pip`，Terminal 使用 `python -m pip`；在 Bash 写 `%pip` 会得到 `fg: %pip: no such job`。安装完成后重启 Notebook 内核，再检查当前解释器：

```python
import sys
from importlib.metadata import version
from qwen_asr import Qwen3ASRModel
print(sys.executable)
print(version("qwen-asr"))
```

### 下载慢的实际观察

阿里镜像曾约 120 kB/s，清华下载同一个 nagisa wheel 一次达到 8.8 MB/s。后续清华其他大包又出现约 230～280 kB/s，因此不能把单次 8.8 MB/s 当成持续保障，也没有证据认定平台统一限速。可优先换清华源、保留 pip 缓存、用明确版本减少回溯；不要靠 `--no-deps` 掩盖冲突。

`--dry-run` 不安装，但解析元数据仍可能下载完整 wheel。下载预置模型权重与下载 Python 包是两回事。

## 任务一：单次识别与文件保存

```python
from pathlib import Path
import torch
from qwen_asr import Qwen3ASRModel

model_path = "/mnt/moark-models/Qwen3-ASR-1.7B"
audio_path = "/mnt/moark-models/L1_exam/asr_demo.wav"
assert Path(model_path).is_dir(), model_path
assert Path(audio_path).is_file(), audio_path

model = Qwen3ASRModel.from_pretrained(
    model_path,
    dtype=torch.bfloat16,
    device_map="cuda:0",
    max_inference_batch_size=1,
    max_new_tokens=256,
)
with torch.inference_mode():
    results = model.transcribe(audio=audio_path, language=None)

text = results[0].text.strip()
if not text:
    raise RuntimeError("识别结果为空")
output = Path("/data/exam/asr_output.txt")
output.parent.mkdir(parents=True, exist_ok=True)
output.write_text(text, encoding="utf-8")
print(results[0].language, text)
print(output)
```

接口可直接接收音频路径，由框架完成音频预处理。不再沿用 Whisper 手动提取 `input_features` 的流程。256 是本轮短音频配置，长音频需要检查转写是否截断。

## 任务二：FastAPI 上传识别

在云端 `/data/exam/asr_api.py` 保存下面代码。Notebook 可在独立单元格首行加 `%%writefile /data/exam/asr_api.py`；先创建 `/data/exam`，不要把魔法命令写入 .py 文件。

```python
import shutil
import tempfile
import threading
from contextlib import asynccontextmanager
from pathlib import Path

import torch
from fastapi import FastAPI, File, Form, HTTPException, UploadFile
from pydantic import BaseModel
from qwen_asr import Qwen3ASRModel

MODEL_NAME = "Qwen3-ASR-1.7B"
lock = threading.Lock()
LANGUAGES = {
    "zh": "Chinese", "en": "English", "ja": "Japanese",
    "ko": "Korean", "yue": "Cantonese",
}

@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.model = Qwen3ASRModel.from_pretrained(
        f"/mnt/moark-models/{MODEL_NAME}",
        dtype=torch.bfloat16,
        device_map="cuda:0",
        max_inference_batch_size=1,
        max_new_tokens=256,
    )
    try:
        yield
    finally:
        del app.state.model
        torch.cuda.empty_cache()

app = FastAPI(lifespan=lifespan)

class TranscriptionResponse(BaseModel):
    text: str

@app.get("/health")
def health():
    return {"status": "ok", "model": MODEL_NAME}

@app.post("/v1/audio/transcriptions", response_model=TranscriptionResponse)
def transcribe(
    file: UploadFile = File(...),
    model: str = Form(MODEL_NAME),
    language: str | None = Form(None),
):
    try:
        if model != MODEL_NAME:
            raise HTTPException(400, f"仅支持 {MODEL_NAME}")
        code = (language or "").strip().lower()
        if code in ("", "auto"):
            target_language = None
        elif code in LANGUAGES:
            target_language = LANGUAGES[code]
        else:
            raise HTTPException(400, "language 支持 zh/en/ja/ko/yue 或留空")
        suffix = Path(file.filename or "").suffix.lower()
        if suffix not in {".wav", ".mp3", ".flac", ".ogg", ".m4a"}:
            raise HTTPException(400, "不支持的音频扩展名")
        with lock:
            with tempfile.TemporaryDirectory(prefix="qwen_asr_") as directory:
                audio = Path(directory) / f"audio{suffix}"
                with audio.open("wb") as output:
                    shutil.copyfileobj(file.file, output)
                if not audio.stat().st_size:
                    raise HTTPException(400, "音频为空")
                with torch.inference_mode():
                    results = app.state.model.transcribe(
                        audio=str(audio), language=target_language,
                    )
                return TranscriptionResponse(text=results[0].text.strip())
    finally:
        file.file.close()
```

文件与字符串均使用 multipart 表单，不用 JSON Body。服务只加载一次模型，锁保护共享模型；临时上传文件自动清理。本接口实现题目要求的子集，不声称支持全部 OpenAI ASR 功能。

### 启动与验收

先重启 Notebook 内核释放单次推理模型，停止占用 8188 的图像 / 文本 / 其他语音服务。保留原 ASR 环境，避免 TTS 安装改变依赖。

```bash
python -m pip show fastapi uvicorn python-multipart
cd /data/exam
python -m uvicorn asr_api:app --host 0.0.0.0 --port 8188 --workers 1
```

只用一个 worker，不加 reload。等待 `Application startup complete.`，保持服务终端打开，在另一个服务器终端执行：

```bash
curl --fail-with-body http://127.0.0.1:8188/health
curl --fail-with-body http://127.0.0.1:8188/v1/audio/transcriptions \
  -F "file=@/mnt/moark-models/L1_exam/asr_demo.wav" \
  -F "model=Qwen3-ASR-1.7B" \
  -F "language=zh" \
  -o /data/exam/asr_api_response.json
cat /data/exam/asr_api_response.json
```

API 返回与任务一文件独立：上面 API 不自动覆盖 `asr_output.txt`。需保留任务一正文，并核对同一音频的识别内容；用户已确认完成，后续仍应归档实际响应和凭证。
