### 坑一：旧启动参数不被接受

```text
--task embed
```

该参数在本实例的 vLLM 0.26.0 不被接受，usage 提供 `--runner {auto,draft,generate,pooling}` 和 `--convert`。实际改为 `--runner pooling` 后启动成功；按实例 `--help` 核对，不能照搬旧教程。

### 坑二：4096 原生维度与题目 1024 维不同

本轮采用 8001 vLLM + 8188 FastAPI 代理，取前 1024 维再 L2 归一化。**截断后必须重新归一化**，上游已经归一化也不能省略。此前会话曾笼统说 vLLM 不支持 dimensions，这不是普遍结论；本页只记录实际成功路线，未验证该构建的原生 dimensions / pooler 降维能力。

8188 实际是兼容接口代理，vLLM 内部监听 8001；并非 vLLM 进程直接监听 8188。用户已确认检测通过，但不能将这两个端口描述混淆。

### 坑四：下载速度与 wheel 选择

实际观察：镜像 range 测试阿里约 5.2 MB/s，pip 全包下载又约 120 kB/s；某次 curl 全包达 12.7 MB/s。不能据此确定 pip 被平台限速或“网络完全没问题”，可能涉及请求方式、缓存、连接或客户端路径差异。最终 Chroma 可正常导入并入库，但没有明确归档唯一生效的下载根因。

同时配置 index 与 extra-index 会使包来源不由书写顺序保证。需要查看 pip 配置和 PIP 环境变量；不要把命令中写清华当成所有文件必从清华下载。用 curl 获取 wheel 时，不用脆弱正则拼完整下载地址：simple 页面可能返回相对链接及 hash 片段。

手动下载 uv 曾选到 musllinux wheel，并用 `uv.whl` 这种不完整文件名安装失败。此容器应匹配其 glibc / manylinux、x86_64 和 Python ABI；保留合法 wheel 文件名。未确认成功的 uv 方案不写成必要安装步骤。

创建 `/data/exam/emb_proxy.py`，以下是对话交付代码整理；仅对 health 增加上游 HTTP 状态检查，防止错误状态被当作健康，不声称此小修订已云端复测：

```python
import httpx
import numpy as np
from fastapi import FastAPI, HTTPException

UPSTREAM = "http://127.0.0.1:8001/v1"
DIM = 1024

app = FastAPI(title="Qwen3-Embedding 1024d Proxy")


@app.get("/health")
async def health():
    async with httpx.AsyncClient(timeout=30) as client:
        try:
            response = await client.get(f"{UPSTREAM}/models")
            response.raise_for_status()
        except httpx.HTTPError as exc:
            raise HTTPException(503, f"upstream 不可达: {exc}") from exc
    return {"status": "ok", "dim": DIM, "upstream": UPSTREAM}


@app.post("/v1/embeddings")
async def embeddings(payload: dict):
    async with httpx.AsyncClient(timeout=180) as client:
        resp = await client.post(f"{UPSTREAM}/embeddings", json=payload)
    if resp.status_code != 200:
        raise HTTPException(resp.status_code, resp.text)

    body = resp.json()
    for item in body["data"]:
        vec = np.asarray(item["embedding"], dtype=np.float32)[:DIM]   # 先截断
        norm = np.linalg.norm(vec)
        item["embedding"] = (vec / norm if norm else vec).tolist()    # 再归一化
    return body
```

本代理仅实现 float 向量路线，客户端显式发送 `encoding_format="float"`；未声称支持完整 OpenAI Embeddings 参数集。

## 任务二：文档切片与 Chroma 存储

原始文档实测为 **4281 字符 / 117 行**。初版将 `##`、`###` 都切成独立块，子主题没有父标题；修改 `split_sections` 使用标题栈后保留 `第二部分：机器学习基础 > 机器学习的三种主要范式` 等完整路径。

下面完整代码已合入会话中的标题层级修订，保存到云端 `/data/exam/build_chroma.py`。**重跑会删除并重建 l1_exam 集合**，仅用于这份实验数据。

```python
import re
from pathlib import Path

import chromadb
import httpx
from chromadb.config import Settings

DOC_PATH    = "/mnt/moark-models/L1_exam/embedding_documents.txt"
API_ROOT    = "http://127.0.0.1:8188"
BASE_URL    = f"{API_ROOT}/v1"
MODEL_NAME  = "Qwen3-Embedding-8B"
PERSIST_DIR = "/data/exam/chroma_db"
COLLECTION  = "l1_exam"

CHUNK_SIZE = 500      # 单个 chunk 目标字符数（含标题前缀）
OVERLAP    = 80       # 同一章内相邻分片的重叠字符数
MIN_CHUNKS = 10       # 题目下限
BATCH      = 32
DIM        = 1024

HEADING_RE = re.compile(r"^(#{1,6})\s+(.*)$")
SENT_SPLIT = re.compile(r"(?<=[。！？!?；;])|(?<=\n)")


# ---------- 服务检查 ----------

def check_service():
    try:
        info = httpx.get(f"{API_ROOT}/health", timeout=5).json()
    except Exception as exc:
        raise SystemExit(
            f"8188 不可用（{exc}）。先启动代理：\n"
            f"  cd /data/exam && python -m uvicorn emb_proxy:app "
            f"--host 0.0.0.0 --port 8188 --workers 1"
        )
    if info.get("dim") not in (None, DIM):
        raise SystemExit(f"代理返回 dim={info['dim']}，期望 {DIM}")
    print(f"服务正常: {info}")


# ---------- 切片 ----------

def split_sections(text):
    doc_title = ""
    sections = []
    stack = {}                              # 层级 -> 标题
    heading, body, level = None, [], 0

    def flush():
        if heading is None and not any(line.strip() for line in body):
            return
        ancestors = [stack[k] for k in sorted(stack) if k < level]
        prefix = " > ".join(ancestors + ([heading] if heading else []))
        sections.append((prefix, "\n".join(body).strip()))

    for line in text.splitlines():
        m = HEADING_RE.match(line.strip())
        if m:
            flush()
            lv, title = len(m.group(1)), m.group(2).strip()
            stack = {k: v for k, v in stack.items() if k < lv}
            level, heading, body = lv, title, []
            if lv == 1 and not doc_title:
                doc_title = title             # 顶级标题进 metadata，不单独成片
                heading, level = None, 0
            else:
                stack[lv] = title
        else:
            body.append(line)
    flush()
    return doc_title, sections


def sentences_of(text):
    out = []
    for block in re.split(r"\n\s*\n", text):
        block = block.strip()
        if not block:
            continue
        for piece in SENT_SPLIT.split(block):
            stripped = piece.strip()
            if not stripped:
                continue
            if piece.endswith("\n"):
                stripped += "\n"        # 保留段落分隔，拼回去更可读
            out.append(stripped)
    return out


def pack(sents, size, overlap):
    """按句子贪心装箱，块与块之间保留 overlap 字符的回退。"""
    chunks, buf, cur = [], [], 0
    for sent in sents:
        parts = [sent[i:i + size] for i in range(0, len(sent), size)] if len(sent) > size else [sent]
        for part in parts:
            if buf and cur + len(part) > size:
                chunks.append("".join(buf).strip())
                while buf and cur > overlap:
                    cur -= len(buf[0])
                    buf.pop(0)
            buf.append(part)
            cur += len(part)
    if buf:
        chunks.append("".join(buf).strip())
    return [c for c in chunks if c]


def split_section(heading, body, size, overlap):
    """标题 + 正文。正文超长时继续按句子分，每片都带上标题作上下文。"""
    prefix = f"{heading}\n" if heading else ""
    budget = max(60, size - len(prefix))
    pieces = pack(sentences_of(body), budget, min(overlap, budget // 4))
    if not pieces:
        return [prefix.strip()] if prefix.strip() else []
    return [(prefix + p).strip() for p in pieces]


def build_chunks(text):
    doc_title, sections = split_sections(text)
    print(f"识别到 {len(sections)} 个章节: {[h or '(无标题)' for h, _ in sections]}")

    size = CHUNK_SIZE
    while True:
        overlap = min(OVERLAP, size // 4)
        chunks = []
        for heading, body in sections:
            chunks.extend(split_section(heading, body, size, overlap))
        if len(chunks) >= MIN_CHUNKS or size <= 100:
            return doc_title, chunks, size, overlap
        size = max(100, int(size * 0.7))


# ---------- 向量化与入库 ----------

def embed_all(texts):
    vectors = []
    with httpx.Client(timeout=180) as client:
        for start in range(0, len(texts), BATCH):
            batch = texts[start:start + BATCH]
            resp = client.post(
                f"{BASE_URL}/embeddings",
                json={"model": MODEL_NAME, "input": batch, "encoding_format": "float"},
            )
            resp.raise_for_status()
            data = sorted(resp.json()["data"], key=lambda d: d["index"])
            vectors.extend(d["embedding"] for d in data)
    if len(vectors) != len(texts):
        raise RuntimeError(f"返回 {len(vectors)} 条，期望 {len(texts)} 条")
    if len(vectors[0]) != DIM:
        raise RuntimeError(f"向量维度 {len(vectors[0])}，期望 {DIM}——是不是绕过了代理直连 8001？")
    return vectors


def main():
    check_service()

    text = Path(DOC_PATH).read_text(encoding="utf-8")
    print(f"原文 {len(text)} 字符 / {len(text.splitlines())} 行")

    doc_title, chunks, size, overlap = build_chunks(text)
    print(f"切成 {len(chunks)} 片（chunk_size={size}, overlap={overlap}）")
    if len(chunks) < MIN_CHUNKS:
        raise RuntimeError(f"只切出 {len(chunks)} 片，不满足 >= {MIN_CHUNKS}")
    print(f"片长分布: min={min(map(len, chunks))} max={max(map(len, chunks))} "
          f"avg={sum(map(len, chunks)) // len(chunks)}")
    for i in (0, len(chunks) // 2, len(chunks) - 1):
        print(f"  样例[{i}] {chunks[i][:70].replace(chr(10), ' ')}...")

    vectors = embed_all(chunks)
    client = chromadb.PersistentClient(
        path=PERSIST_DIR,
        settings=Settings(anonymized_telemetry=False),
    )
    try:
        client.delete_collection(COLLECTION)
        print(f"已删除旧的 collection {COLLECTION}")
    except Exception:
        pass

    col = client.get_or_create_collection(
        name=COLLECTION, metadata={"hnsw:space": "cosine"},
    )
    col.add(
        ids=[f"chunk_{i:03d}" for i in range(len(chunks))],
        documents=chunks,
        embeddings=vectors,
        metadatas=[
            {
                "source": Path(DOC_PATH).name,
                "doc_title": doc_title,
                "chunk_index": i,
                "char_len": len(c),
            }
            for i, c in enumerate(chunks)
        ],
    )
    print(f"入库完成: {PERSIST_DIR} / {COLLECTION} 共 {col.count()} 条")

    query = "什么是机器学习"
    qvec = embed_all([query])[0]
    res = col.query(query_embeddings=[qvec], n_results=3)
    print(f"\n自检查询「{query}」:")
    for doc, dist in zip(res["documents"][0], res["distances"][0]):
        print(f"  dist={dist:.4f}  {doc[:60].replace(chr(10), ' ')}...")


if __name__ == "__main__":
    main()
```

保存到云端 `/data/exam/rerank_eval.py`。脚本兼容会话讨论的 rerank / score 路由形状，**本次实际命中 `/v1/rerank`**：

```python
"""任务三：bge-reranker-v2-m3 重排，对比结果写入 /data/exam/reranking_results.json"""
import json
import sys
from pathlib import Path

import chromadb
import httpx
from chromadb.config import Settings

EMB_BASE    = "http://127.0.0.1:8188/v1"
EMB_MODEL   = "Qwen3-Embedding-8B"
PERSIST_DIR = "/data/exam/chroma_db"
COLLECTION  = "l1_exam"

RERANK_ROOT  = "http://127.0.0.1:8002"
RERANK_MODEL = "bge-reranker-v2-m3"

OUT_PATH = Path("/data/exam/reranking_results.json")
TOP_K    = 10
QUERY    = sys.argv[1] if len(sys.argv) > 1 else "什么是深度学习？"

CANDIDATES = [("/v1/rerank", "rerank"), ("/rerank", "rerank"),
              ("/v1/score", "score"),   ("/score", "score")]
_chosen = None


def embed_query(text):
    r = httpx.post(f"{EMB_BASE}/embeddings",
                   json={"model": EMB_MODEL, "input": [text],
                         "encoding_format": "float"}, timeout=120)
    r.raise_for_status()
    vec = r.json()["data"][0]["embedding"]
    if len(vec) != 1024:
        raise SystemExit(f"向量维度 {len(vec)} != 1024，是不是绕过了 8188 代理？")
    return vec


def retrieve(query, k):
    col = chromadb.PersistentClient(
        path=PERSIST_DIR, settings=Settings(anonymized_telemetry=False)
    ).get_collection(COLLECTION)
    if col.count() == 0:
        raise SystemExit("collection 为空，先跑 build_chroma.py")
    res = col.query(query_embeddings=[embed_query(query)], n_results=k,
                    include=["documents", "distances", "metadatas"])
    return [(res["ids"][0][i], res["documents"][0][i], res["distances"][0][i])
            for i in range(len(res["ids"][0]))]


def _payload(shape, query, texts):
    if shape == "rerank":
        return {"model": RERANK_MODEL, "query": query,
                "documents": texts, "top_n": len(texts)}
    return {"model": RERANK_MODEL, "text_1": query, "text_2": texts}


def _scores(body, n):
    if "results" in body:                       # Jina / Cohere 风格
        items = sorted(body["results"], key=lambda x: x["index"])
        vals = [it.get("relevance_score", it.get("score")) for it in items]
    else:                                       # vLLM Score API
        items = sorted(body.get("data", []), key=lambda x: x["index"])
        vals = [it.get("score") for it in items]
    if len(vals) != n or any(v is None for v in vals):
        raise ValueError(f"返回 {len(vals)} 个分数，期望 {n}")
    return [float(v) for v in vals]


def rerank(query, texts):
    global _chosen
    last = None
    for path, shape in ([_chosen] if _chosen else CANDIDATES):
        try:
            r = httpx.post(f"{RERANK_ROOT}{path}",
                           json=_payload(shape, query, texts), timeout=120)
            if r.status_code in (404, 405):
                last = f"{path} -> HTTP {r.status_code}"
                continue
            r.raise_for_status()
            scores = _scores(r.json(), len(texts))
            _chosen = (path, shape)
            print(f"重排接口: POST {RERANK_ROOT}{path}  ({shape})")
            return scores
        except Exception as exc:
            last = f"{path} -> {exc}"
    raise SystemExit(f"没有可用的重排接口，最后一次: {last}\n"
                     f"先查 curl {RERANK_ROOT}/v1/models")


def main():
    cand  = retrieve(QUERY, TOP_K)
    texts = [doc for _, doc, _ in cand]

    print(f"query: {QUERY}")
    print(f"向量召回 Top-{len(cand)}:")
    for i, (cid, doc, dist) in enumerate(cand, 1):
        print(f"  {i:2d}. {cid:>10}  dist={dist:.4f}  sim={1 - dist:.4f}  "
              f"{doc.splitlines()[0]}")

    scores  = rerank(QUERY, texts)
    initial = [{"doc_id": cid, "initial_rank": i,
                "embedding_score": round(1 - dist, 6), "text": doc}
               for i, (cid, doc, dist) in enumerate(cand, 1)]

    ranked = sorted(range(len(cand)), key=lambda i: scores[i], reverse=True)
    reranked = [{"doc_id": cand[i][0], "initial_rank": i + 1,
                 "reranked_rank": r + 1,
                 "reranker_score": round(scores[i], 6), "text": cand[i][1]}
                for r, i in enumerate(ranked)]

    OUT_PATH.parent.mkdir(parents=True, exist_ok=True)
    OUT_PATH.write_text(json.dumps(
        {"query": QUERY, "embedding_top_k": TOP_K,
         "initial_top10": initial, "reranked_top10": reranked},
        ensure_ascii=False, indent=2), encoding="utf-8")

    print("\n重排后:")
    for item in reranked:
        move = item["initial_rank"] - item["reranked_rank"]
        arrow = "↑" if move > 0 else ("↓" if move < 0 else "=")
        print(f"  {item['reranked_rank']:2d}. {item['doc_id']:>10}  "
              f"score={item['reranker_score']:+.4f}  {arrow}{abs(move)}  "
              f"{item['text'].splitlines()[0]}")

    moved = sum(1 for it in reranked if it["initial_rank"] != it["reranked_rank"])
    print(f"\n位次变化: {moved}/{len(reranked)} 条")
    print(f"已写入: {OUT_PATH}")


if __name__ == "__main__":
    main()
```
