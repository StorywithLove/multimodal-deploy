# 图片大模型（vision）

图片生成（T2I）与图像理解类模型部署与测评。委托模型示例：Qwen-Image、Stable Diffusion 系列等。

## 约定

每个模型一个子目录，包含：

```
<model-name>/
├─ deploy.sh     # 部署/推理脚本
├─ record.md     # 环境、命令、踩坑、产出、测评
└─ outputs/      # 产出图片与日志
```
